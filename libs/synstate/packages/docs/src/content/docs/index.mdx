## Features

<CardGrid>
    <Card title="Simple State Management" icon="pencil">
        Easy-to-use `createState` and `createReducer` similar to React
        `useState` / `useReducer` for global state.
    </Card>
    <Card title="High Performance" icon="rocket">
        Glitch-free O(n) propagation — up to **30× faster** than Jotai and **16×
        faster** than Redux. See
        [benchmarks](/synstate/guides/library-comparison/benchmark/).
    </Card>
    <Card title="Lightweight" icon="seti:favicon">
        {/* bundle-size:synstate */}~4.5 kB min+gzip
        {/* /bundle-size:synstate */} with only one external runtime dependency.
    </Card>
    <Card title="Built-in Async Operators" icon="setting">
        `debounce`, `throttle`, `switchMap`, and more — handle complex async
        flows in a unified, declarative API without external libraries.
    </Card>
    <Card title="React-Optimized" icon="seti:react">
        Fully compatible with React Compiler. `synstate-react-hooks` lets you
        add global state to any component in just a few lines.
    </Card>
    <Card title="Framework Agnostic" icon="random">
        Core library works as-is with vanilla JavaScript, Vue, Svelte, or any
        framework. For React and Preact, hooks wrappers are available. For
        Preact, a Preact Signals integration is also provided.
    </Card>
</CardGrid>
