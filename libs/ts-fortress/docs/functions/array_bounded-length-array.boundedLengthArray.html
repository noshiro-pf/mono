      Creates a Type for a readonly array whose length is within the inclusive range [min, max], typed as the branded BoundedLengthArray instead of the union of tuple types produced by boundedLengthTuple.

      Because the length constraint lives only in the brand, no union of tuples of the element type is ever constructed, which keeps type-checking cheap even when A is a large type.
