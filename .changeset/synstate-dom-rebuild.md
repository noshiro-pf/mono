synstate-dom is rebuilt on the rebuilt synstate, which it takes as a peer dependency. A binding is one effect object run once per update after every value is up to date, a branch component (`If`, `MatchOptional`, `MatchResult`, `Switch`) unmounts a branch before the branch's own nodes recompute from the value that rules it out, and a component's nodes are disposed with the owner of its branch or row. What an application changes is on the documentation's [Changes from synstate-dom 0.13](https://noshiro-pf.github.io/mono/synstate-dom/background/changes-from-synstate-dom/) page.
