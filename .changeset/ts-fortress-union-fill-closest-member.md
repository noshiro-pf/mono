`t.union`'s `fill`, when the union is given no `defaultType`, repairs a value that no member accepts with the record or tuple member closest to it, the one that keeps the most of the value's keys against those it rejects or does not declare, when no other member of the value's runtime category is as close, and with the only member of that category when it is a record. It repaired every such value with the first member, so `t.union([t.nullType, t.record({ x: t.number(), y: t.number() })]).fill({ x: 1 })` was `null`; it is now `{ x: 1, y: 0 }`, and a discriminated union repairs `{ kind: 'circle', radius: '5' }` to the `circle` variant whatever variant comes first. Any other value is still repaired with the first member: one that no record or tuple member shares a runtime category with, one that no member keeps a key of (a tuple of another length is never a repair), one of whose category a member checks the value as a whole (an `array`, a `keyValueRecord`, or a `t.recursion` that is not a record), and one that two members are equally close to. A union given a `defaultType` repairs every such value with it, as before, so `t.union([t.nullType, X], { defaultType: t.nullType })` keeps repairing to `null`. In a `t.recursion` of a record such as `t.union([t.nullType, Node])`, a node that is not valid is now repaired as a node rather than cut to `null`.
