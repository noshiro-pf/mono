`a`, `script`, `style` and `title`, the tags HTML and SVG share, are created in the SVG namespace when they are mounted under an SVG element other than `foreignObject`, and as HTML elements anywhere else, as an HTML parser and React decide it. Inside an `<svg>`, a `<title>` now names its parent and an `<a>` draws the shapes it holds; a `<title>` an `If` mounts later, the rows a `For` adds later and what `render` puts into an SVG container follow the same rule, and a `Portal` takes the namespace of its target. An attribute of those four is written lower-case on the SVG element (`tabIndex` becomes `tabindex`).
