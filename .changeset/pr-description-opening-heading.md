`pr-description` and `open-pr --body-file` can ask a pull request's description to open with a given `##` section, set by `pullRequestDescription.openingHeading` in `.github/unblock-prs.json`. The `pr-description` README now says what a description should contain and in what order. A translation now repeats the original's code blocks, unchanged and in order, rather than referring to them, so that it reads on its own.
