Emits the `n`-th values of all `parents` as a tuple, once each of them has emitted its `n`-th. The values the parents hold at the start count as their first. Values wait in a queue per parent until the slowest catches up.

{/* /reference */}

## Example

```tsx
import { createValueEmitter, zip } from 'synstate-next';

const [questions, ask] = createValueEmitter<string>();

const [answers, answer] = createValueEmitter<number>();

const mut_pairs: string[] = [];

zip([questions, answers]).subscribe(([q, a]) => {
    mut_pairs.push(`${q} = ${a}`);
});

ask('1 + 1');

ask('2 + 2');

answer(2);

answer(4);

assert.deepStrictEqual(mut_pairs, ['1 + 1 = 2', '2 + 2 = 4']);
```
