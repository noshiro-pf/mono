Emits the value of whichever parent emitted in this update (the first of them, if several did). Starts from the value of the parent whose value was given last, by the same rule: of values given in one update, the first parent's. Holds no value while no parent holds one.

{/* /reference */}

## Example

```tsx
import { createValueEmitter, merge } from 'synstate-next';

const [mouse, fromMouse] = createValueEmitter<string>();

const [keyboard, fromKeyboard] = createValueEmitter<string>();

const mut_inputs: string[] = [];

merge([mouse, keyboard]).subscribe((input) => {
    mut_inputs.push(input);
});

fromMouse('click');

fromKeyboard('enter');

assert.deepStrictEqual(mut_inputs, ['click', 'enter']);
```
