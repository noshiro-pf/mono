A state written only by `dispatch`, through `reducer`. A dispatch made inside an operator such as `map` or `derive`, while an update is recomputing values, waits until the subscribers and bindings of the update under way have run, and then reduces the state the writes before it left. `dispatch` returns nothing; read the state with `getSnapshot`.

{/* /reference */}

## Example

```tsx
import { createReducer } from 'synstate-next';

type Action = Readonly<{ type: 'increment' } | { type: 'add'; amount: number }>;

const [count, dispatch, { getSnapshot }] = createReducer(
    (n: number, action: Action) =>
        action.type === 'increment' ? n + 1 : n + action.amount,
    0,
);

dispatch({ type: 'increment' });

dispatch({ type: 'add', amount: 10 });

assert.strictEqual(count.value, 11);

assert.strictEqual(getSnapshot(), 11);
```
