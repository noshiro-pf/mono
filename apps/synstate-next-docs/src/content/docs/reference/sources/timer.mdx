Emits `0` once, `milliseconds` after it is created, and settles. Disposing it clears the timer.

{/* /reference */}

## Marble diagram

<MarbleDiagram slug="timer" />

## Example

```tsx
import { timer } from 'synstate-next';

const mut_fired: number[] = [];

timer(300).subscribe((n) => {
    mut_fired.push(n);
});

await vi.advanceTimersByTimeAsync(299);

assert.deepStrictEqual(mut_fired, []);

await vi.advanceTimersByTimeAsync(1);

assert.deepStrictEqual(mut_fired, [0]);
```
