{/* reference:jsdoc */}

Creates a source that emits by itself, from another library or an event: a creator written outside the package. `setup` runs once, at creation. The source holds `initialValue` if given, and nothing until it first emits otherwise. It belongs to the current owner as every observable does. `setup` runs with the source as the current owner, so what it creates and the cleanups it registers (`ctx.onCleanup`, or `onCleanup`) belong to the source. Disposing it runs the cleanups, newest first, and then disposes what `setup` created, as an owner does. A cleanup is registered, not returned.

{/* /reference */}

## Example

```tsx
import { createSource, type Observable } from 'synstate-next';
import { Optional } from 'ts-std-forge';

const everyFrame = (milliseconds: number): Observable<number> =>
    createSource<number>((ctx) => {
        let mut_frame = 0;

        const id = setInterval(() => {
            mut_frame += 1;

            ctx.emit(mut_frame);
        }, milliseconds);

        ctx.onCleanup(() => {
            clearInterval(id);
        });
    });

const frames = everyFrame(16);

await vi.advanceTimersByTimeAsync(50);

assert.deepStrictEqual(frames.getSnapshot(), Optional.some(3));

// Disposing it runs the cleanup, which clears the interval.
frames.dispose();

await vi.advanceTimersByTimeAsync(50);

assert.deepStrictEqual(frames.getSnapshot(), Optional.some(3));
```
