Emits `0` in the task after it is created (or, with `emitInitial: false`, `1` one interval later), then the next integer every `milliseconds`. With `times` (a positive integer, or `Infinity`, the default), it settles after that many values and clears its timers; otherwise it runs until disposed. Any count is accepted, beyond `Number.MAX_SAFE_INTEGER` too.

## Example

```tsx
import { counter } from 'synstate-next';

const mut_ticks: number[] = [];

counter(100, { times: 3 }).subscribe((n) => {
    mut_ticks.push(n);
});

await vi.advanceTimersByTimeAsync(1000);

// 0 at once, then one every 100 ms, three values in all.
assert.deepStrictEqual(mut_ticks, [0, 1, 2]);
```
