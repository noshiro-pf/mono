Drops a value equal to the one held (`Object.is` unless `equals` says otherwise). A derived value already stops an update when it does not change; this is for an event source, or for a comparison of its own.

{/* /reference */}

{/* reference:init-kind */}

Its result holds a value whenever the source does: on an `InitializedObservable`, `pipe` gives one ([`keep`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createValueEmitter, skipIfNoChange } from 'synstate-next';

const [reading, read] = createValueEmitter<number>();

// An event source passes every value; this drops the repeats.
const changes = reading.pipe(skipIfNoChange());

const mut_seen: number[] = [];

changes.subscribe((r) => {
    mut_seen.push(r);
});

read(1);

read(1);

read(2);

assert.deepStrictEqual(mut_seen, [1, 2]);
```
