Gives each value of the source the values `other` emitted since the previous one, in order: those emitted in the same update included, those it held before this node was created not.

{/* /reference */}

{/* reference:operator-kind */}

Its result holds a value whenever the source does: on an `InitializedObservable`, `pipe` gives one ([`KeepInitialValueOperator`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import {
    createEventEmitter,
    createValueEmitter,
    withBufferedFrom,
} from 'synstate-next';

const [logged, log] = createValueEmitter<string>();

const [flushed, flush] = createEventEmitter();

const mut_batches: (readonly string[])[] = [];

flushed.pipe(withBufferedFrom(logged)).subscribe(([, lines]) => {
    mut_batches.push(lines);
});

log('a');

log('b');

flush();

log('c');

flush();

assert.deepStrictEqual(mut_batches, [['a', 'b'], ['c']]);
```
