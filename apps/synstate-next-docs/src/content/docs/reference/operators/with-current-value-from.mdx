Pairs each value of the source with the value `other` holds, settled for the same update. `other` does not wake it: a change of `other` alone emits nothing. Emits nothing while `other` holds no value.

{/* /reference */}

{/* reference:init-kind */}

Its result may hold no value even when the source holds one: `pipe` gives an `Observable` ([`drop`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import {
    createEventEmitter,
    createState,
    withCurrentValueFrom,
} from 'synstate-next';

const [draft, setDraft] = createState('');

const [submitted, submit] = createEventEmitter();

const mut_sent: string[] = [];

submitted.pipe(withCurrentValueFrom(draft)).subscribe(([, text]) => {
    mut_sent.push(text);
});

// Typing alone sends nothing.
setDraft('hi');

setDraft('hello');

submit();

assert.deepStrictEqual(mut_sent, ['hello']);
```
