Passes the values of the source while `predicate` holds for them; from the first value it fails for, passes nothing, keeping the last value passed.

{/* /reference */}

{/* reference:operator-kind */}

Its result may hold no value even when the source holds one: `pipe` gives an `Observable` ([`DropInitialValueOperator`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createValueEmitter, takeWhile } from 'synstate-next';

const [progress, report] = createValueEmitter<number>();

const running = progress.pipe(takeWhile((p) => p < 100));

const mut_seen: number[] = [];

running.subscribe((p) => {
    mut_seen.push(p);
});

report(30);

report(80);

report(100);

report(40);

assert.deepStrictEqual(mut_seen, [30, 80]);
```
