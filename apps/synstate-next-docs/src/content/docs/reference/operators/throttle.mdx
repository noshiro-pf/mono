Passes a value at once, then drops the values of the next `milliseconds`. Holds the value the source holds at the start, without opening a window.

{/* /reference */}

{/* reference:init-kind */}

Its result holds a value whenever the source does: on an `InitializedObservable`, `pipe` gives one ([`keep`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createValueEmitter, throttle } from 'synstate-next';

const [scrolled, scroll] = createValueEmitter<number>();

const mut_seen: number[] = [];

scrolled.pipe(throttle(100)).subscribe((y) => {
    mut_seen.push(y);
});

scroll(10);

scroll(20);

await vi.advanceTimersByTimeAsync(100);

scroll(30);

// The first value of each window passes; the rest are dropped.
assert.deepStrictEqual(mut_seen, [10, 30]);
```
