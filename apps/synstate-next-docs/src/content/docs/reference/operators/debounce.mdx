Emits the latest value once `milliseconds` have passed without another, in an update of its own. Holds the value the source holds at the start; disposing it drops a value still waiting.

{/* /reference */}

{/* reference:operator-kind */}

Its result holds a value whenever the source does: on an `InitializedObservable`, `pipe` gives one ([`KeepInitialValueOperator`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createState, debounce } from 'synstate-next';

const [query, setQuery] = createState('');

const settled = query.pipe(debounce(300));

setQuery('s');

await vi.advanceTimersByTimeAsync(100);

setQuery('sy');

await vi.advanceTimersByTimeAsync(100);

setQuery('syn');

// Still the value it held at the start.
assert.strictEqual(settled.value, '');

await vi.advanceTimersByTimeAsync(300);

assert.strictEqual(settled.value, 'syn');
```
