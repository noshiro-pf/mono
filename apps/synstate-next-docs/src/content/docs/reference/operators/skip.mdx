Drops the first `count` values of the source, the one it holds at the start included, and passes the rest. `count` is a non-negative integer.

{/* /reference */}

{/* reference:operator-kind */}

Its result may hold no value even when the source holds one: `pipe` gives an `Observable` ([`DropInitialValueOperator`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createState, skip } from 'synstate-next';
import { Optional } from 'ts-std-forge';

const [query, setQuery] = createState('');

// Leaves out the value held at the start: only what the user typed.
const typed = query.pipe(skip(1));

assert.isFalse(typed.hasValue);

setQuery('syn');

assert.deepStrictEqual(typed.getSnapshot(), Optional.some('syn'));
```
