{/* reference:jsdoc */}

Follows every observable that `project` returns, emitting whatever any of them emits. What a projection creates belongs to an owner of its own, disposed once its observable is settled (a `timer` that fired, a settled promise) or when this node is disposed.

The inner observable's value at the time of the projection joins the update that caused it, unless this node already emitted in that update. A later emission arrives in an update of its own. Every value is delivered, as an event source's are: values that meet in one update are delivered one update after another, in the order they arrived.

{/* /reference */}

{/* reference:init-kind */}

Its result may hold no value even when the source holds one: `pipe` gives an `Observable` ([`drop`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createValueEmitter, map, mergeMap, timer } from 'synstate-next';

const [uploaded, upload] = createValueEmitter<string>();

// Every upload runs to the end, the slow one included.
const done = uploaded.pipe(
    mergeMap((name) =>
        timer(name === 'big' ? 300 : 100).pipe(map(() => `${name} done`)),
    ),
);

const mut_seen: string[] = [];

done.subscribe((message) => {
    mut_seen.push(message);
});

upload('big');

upload('small');

await vi.advanceTimersByTimeAsync(300);

assert.deepStrictEqual(mut_seen, ['small done', 'big done']);
```
