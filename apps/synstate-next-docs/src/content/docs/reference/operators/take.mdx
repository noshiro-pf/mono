Passes the first `count` values of the source, the one it holds at the start included, and then nothing, keeping the last value passed. `count` is a positive integer.

{/* /reference */}

{/* reference:init-kind */}

Its result holds a value whenever the source does: on an `InitializedObservable`, `pipe` gives one ([`keep`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createValueEmitter, take } from 'synstate-next';

const [clicked, click] = createValueEmitter<number>();

const firstTwo = clicked.pipe(take(2));

const mut_seen: number[] = [];

firstTwo.subscribe((n) => {
    mut_seen.push(n);
});

click(1);

click(2);

click(3);

assert.deepStrictEqual(mut_seen, [1, 2]);

// It keeps the last value it passed.
assert.strictEqual(firstTwo.getSnapshot(), 2);
```
