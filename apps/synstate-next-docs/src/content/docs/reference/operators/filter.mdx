Passes on the values that satisfy `predicate`. A type guard narrows the values passed on.

{/* /reference */}

{/* reference:init-kind */}

Its result may hold no value even when the source holds one: `pipe` gives an `Observable` ([`drop`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createValueEmitter, filter } from 'synstate-next';

const [keyPressed, pressKey] = createValueEmitter<string>();

const enter = keyPressed.pipe(filter((key) => key === 'Enter'));

const mut_seen: string[] = [];

enter.subscribe((key) => {
    mut_seen.push(key);
});

pressKey('a');

pressKey('Enter');

assert.deepStrictEqual(mut_seen, ['Enter']);
```
