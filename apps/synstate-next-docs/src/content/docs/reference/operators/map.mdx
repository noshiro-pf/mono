Maps each value with `fn`, and emits the result unless it equals the one held (`Object.is` unless `equals` says otherwise), so a result that did not change wakes nothing below. For an event mapped to a value that repeats, pass `equals: () => false`.

{/* /reference */}

{/* reference:init-kind */}

Its result holds a value whenever the source does: on an `InitializedObservable`, `pipe` gives one ([`keep`](/mono/synstate-next/guides/deriving-values/#pipe)).

{/* /reference */}

## Example

```tsx
import { createState, map } from 'synstate-next';

const [celsius, setCelsius] = createState(0);

const fahrenheit = celsius.pipe(map((c) => (c * 9) / 5 + 32));

setCelsius(100);

assert.strictEqual(fahrenheit.value, 212);
```
