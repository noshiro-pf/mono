## Features

<CardGrid>
    <Card title="Glitch-free" icon="approve-check">
        A derived value is computed once per update, after all of its parents,
        diamonds included. Nothing ever reads a value from halfway through an
        update.
    </Card>
    <Card title="Subscribers see a settled graph" icon="approve-check">
        Subscribers are effects: they run after the update has reached every
        node it changes. A write made while the update propagates waits for it
        to end instead of interrupting it.
    </Card>
    <Card title="Cut off at the first unchanged value" icon="random">
        A node that computes the value it already holds passes nothing on, so
        the part of the graph below it is not visited at all.
    </Card>
    <Card title="One owner, one lifetime" icon="setting">
        Everything made while an owner runs belongs to it. Dispose the owner and
        its derived values, subscriptions, timers and requests go with it.
        Nothing has to be completed.
    </Card>
    <Card title="Types say what holds a value" icon="pencil">
        A state, or a `map` of one, is an `InitializedObservable` with a
        `.value`. An event, or a `filter`, is an `Observable` that may hold
        nothing yet. `pipe` works out which one you get.
    </Card>
    <Card title="Small and regular" icon="rocket">
        One way to write each thing: a transformation is a `map`, a choice is a
        `switchMap`, an operator of your own is a `createDerived`. No aliases,
        no one-line operators to learn.
    </Card>
</CardGrid>
