## 特徴

<CardGrid>
    <Card title="グリッチがない" icon="approve-check">
        派生値は 1 回の更新につき 1
        回、親がすべて済んだ後に計算されます。ダイヤモンド型の依存でも同じです。更新途中の値を読むことはありません。
    </Card>
    <Card title="購読者は落ち着いたグラフを見る" icon="approve-check">
        購読者は effect
        で、更新が変わるノードすべてに届いてから実行されます。伝播の途中に行った書き込みは、伝播を中断せず、終わるまで待ちます。
    </Card>
    <Card title="変わらない値で打ち切る" icon="random">
        すでに持っている値を計算したノードは何も伝えないので、その下のグラフはまったく辿られません。
    </Card>
    <Card title="寿命は owner ひとつ" icon="setting">
        owner の実行中に作ったものはすべてその owner に属します。owner
        を破棄すれば、派生値・購読・タイマー・リクエストも一緒に消えます。完了を伝える必要はありません。
    </Card>
    <Card title="値を持つかどうかが型でわかる" icon="pencil">
        状態やその `map` は `.value` を持つ `InitializedObservable`、イベントや
        `filter` はまだ値を持たないことがある `Observable`
        です。どちらになるかは `pipe` が型で計算します。
    </Card>
    <Card title="小さく、規則的" icon="rocket">
        1 つのことに書き方は 1 つです。変換は `map`、切り替えは
        `switchMap`、独自のオペレーターは `createDerived`。別名や 1
        行で書けるだけのオペレーターを覚える必要はありません。
    </Card>
</CardGrid>
