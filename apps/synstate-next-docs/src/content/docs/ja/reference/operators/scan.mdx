`seed` から始めて、値を `reducer` で畳み込みます。最初から `seed`（か、最初の値を畳み込んだ値）を持ち、ソースが値を流すたびに流します。

{/* reference:operator-kind */}

結果は常に値を持ちます。`pipe` の結果は `InitializedObservable` です（[`ProvideInitialValueOperator`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import { createValueEmitter, scan } from 'synstate-next';

const [amount, add] = createValueEmitter<number>();

const total = amount.pipe(scan((sum, n) => sum + n, 0));

// `scan` holds its seed from the start.
assert.strictEqual(total.value, 0);

add(10);

add(5);

assert.strictEqual(total.value, 15);
```
