`predicate` が成り立つ間、ソースの値を捨てます。成り立たない最初の値からは、すべての値を流します。

{/* reference:operator-kind */}

ソースが値を持っていても、結果は値を持たないことがあります。`pipe` の結果は `Observable` です（[`DropInitialValueOperator`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import { createValueEmitter, skipWhile } from 'synstate-next';

const [temperature, read] = createValueEmitter<number>();

// Ignore the readings until the sensor has warmed up.
const warm = temperature.pipe(skipWhile((t) => t < 20));

const mut_seen: number[] = [];

warm.subscribe((t) => {
    mut_seen.push(t);
});

read(5);

read(21);

read(18);

assert.deepStrictEqual(mut_seen, [21, 18]);
```
