`predicate` が成り立つ間、ソースの値を流します。成り立たない最初の値からは何も流さず、最後に流した値を持ち続けます。

{/* reference:operator-kind */}

ソースが値を持っていても、結果は値を持たないことがあります。`pipe` の結果は `Observable` です（[`DropInitialValueOperator`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import { createValueEmitter, takeWhile } from 'synstate-next';

const [progress, report] = createValueEmitter<number>();

const running = progress.pipe(takeWhile((p) => p < 100));

const mut_seen: number[] = [];

running.subscribe((p) => {
    mut_seen.push(p);
});

report(30);

report(80);

report(100);

report(40);

assert.deepStrictEqual(mut_seen, [30, 80]);
```
