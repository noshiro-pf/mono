ソースの最初の `count` 個の値を、最初に持っている値も含めて捨て、残りを流します。`count` は 0 以上の整数です。

{/* reference:operator-kind */}

ソースが値を持っていても、結果は値を持たないことがあります。`pipe` の結果は `Observable` です（[`DropInitialValueOperator`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import { createState, skip } from 'synstate-next';

const [query, setQuery] = createState('');

// Leaves out the value held at the start: only what the user typed.
const typed = query.pipe(skip(1));

assert.isFalse(typed.hasValue);

setQuery('syn');

assert.strictEqual(typed.getSnapshot(), 'syn');
```
