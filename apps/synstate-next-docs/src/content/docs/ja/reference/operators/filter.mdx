`predicate` を満たす値を流します。型ガードを渡すと、流す値の型が絞り込まれます。

{/* reference:operator-kind */}

ソースが値を持っていても、結果は値を持たないことがあります。`pipe` の結果は `Observable` です（[`DropInitialValueOperator`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import { createValueEmitter, filter } from 'synstate-next';

const [keyPressed, pressKey] = createValueEmitter<string>();

const enter = keyPressed.pipe(filter((key) => key === 'Enter'));

const mut_seen: string[] = [];

enter.subscribe((key) => {
    mut_seen.push(key);
});

pressKey('a');

pressKey('Enter');

assert.deepStrictEqual(mut_seen, ['Enter']);
```
