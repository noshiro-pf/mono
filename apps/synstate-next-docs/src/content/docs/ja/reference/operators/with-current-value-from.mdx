ソースの各値を、同じ更新で落ち着いた `other` の値とペアにします。`other` はこれを起こしません。`other` だけが変わっても何も流しません。`other` が値を持たない間は何も流しません。

{/* reference:init-kind */}

ソースが値を持っていても、結果は値を持たないことがあります。`pipe` の結果は `Observable` です（[`drop`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import {
    createEventEmitter,
    createState,
    withCurrentValueFrom,
} from 'synstate-next';

const [draft, setDraft] = createState('');

const [submitted, submit] = createEventEmitter();

const mut_sent: string[] = [];

submitted.pipe(withCurrentValueFrom(draft)).subscribe(([, text]) => {
    mut_sent.push(text);
});

// Typing alone sends nothing.
setDraft('hi');

setDraft('hello');

submit();

assert.deepStrictEqual(mut_sent, ['hello']);
```
