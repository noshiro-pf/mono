各値を `fn` で変換し、結果が持っている値と等しくなければ流します（`equals` を渡さなければ `Object.is` で比べます）。変わらなかった結果は、下にあるものを計算し直させません。繰り返す値に変換するイベントには `equals: () => false` を渡してください。

{/* reference:operator-kind */}

ソースが値を持てば、結果も値を持ちます。`pipe` は `InitializedObservable` をそのまま保ちます（[`KeepInitialValueOperator`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import { createState, map } from 'synstate-next';

const [celsius, setCelsius] = createState(0);

const fahrenheit = celsius.pipe(map((c) => (c * 9) / 5 + 32));

setCelsius(100);

assert.strictEqual(fahrenheit.value, 212);
```
