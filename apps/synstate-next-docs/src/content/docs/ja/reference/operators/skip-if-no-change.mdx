持っている値と等しい値を捨てます（`equals` を渡さなければ `Object.is` で比べます）。派生した値は、変わらなければすでにそこで更新を止めるので、これはイベントソースや、独自の比較のためのものです。

{/* reference:operator-kind */}

ソースが値を持てば、結果も値を持ちます。`pipe` は `InitializedObservable` をそのまま保ちます（[`KeepInitialValueOperator`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import { createValueEmitter, skipIfNoChange } from 'synstate-next';

const [reading, read] = createValueEmitter<number>();

// An event source passes every value; this drops the repeats.
const changes = reading.pipe(skipIfNoChange());

const mut_seen: number[] = [];

changes.subscribe((r) => {
    mut_seen.push(r);
});

read(1);

read(1);

read(2);

assert.deepStrictEqual(mut_seen, [1, 2]);
```
