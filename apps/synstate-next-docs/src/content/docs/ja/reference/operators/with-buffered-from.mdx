ソースの各値に、直前の値から後に `other` が流した値を順に付けます。同じ更新で流したものは含み、このノードを作る前から持っていたものは含みません。

{/* reference:operator-kind */}

ソースが値を持てば、結果も値を持ちます。`pipe` は `InitializedObservable` をそのまま保ちます（[`KeepInitialValueOperator`](/mono/synstate-next/ja/guides/deriving-values/#pipe)）。

{/* /reference */}

## 例

```tsx
import {
    createEventEmitter,
    createValueEmitter,
    withBufferedFrom,
} from 'synstate-next';

const [logged, log] = createValueEmitter<string>();

const [flushed, flush] = createEventEmitter();

const mut_batches: (readonly string[])[] = [];

flushed.pipe(withBufferedFrom(logged)).subscribe(([, lines]) => {
    mut_batches.push(lines);
});

log('a');

log('b');

flush();

log('c');

flush();

assert.deepStrictEqual(mut_batches, [['a', 'b'], ['c']]);
```
