`setTrue`・`setFalse`・`toggle` を持つ真偽値の状態です。

## 例

```tsx
import { createBooleanState } from 'synstate-next';

const [isOpen, { setTrue, setFalse, toggle }] = createBooleanState(false);

setTrue();

assert.isTrue(isOpen.value);

toggle();

assert.isFalse(isOpen.value);

toggle();

setFalse();

assert.isFalse(isOpen.value);
```
