observable・セッター・その他の操作をタプルにした状態です。それぞれを別の場所に渡すコードのためのものです。セッターは何も返しません。グラフのドレイン中の書き込みはそのラウンドの effect が実行されてから適用されるので、返すべき値はまだ決まっていません。状態は `getSnapshot` で読みます。

## 例

```tsx
import { createState } from 'synstate-next';

const [count, setCount, { updateState, resetState, getSnapshot }] =
    createState(0);

const mut_seen: number[] = [];

count.subscribe((n) => {
    mut_seen.push(n);
});

setCount(5);

updateState((n) => n + 1);

assert.strictEqual(getSnapshot(), 6);

resetState();

assert.deepStrictEqual(mut_seen, [0, 5, 6, 0]);
```
