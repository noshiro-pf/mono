`initial` を持つ状態を作ります。

更新が値を計算し直している間に `map` や `derive` などのオペレーターの中で行った書き込みは進行中の更新の購読者と束縛が実行されてから適用され、購読者や束縛の書き込みはすぐに適用されます。どちらも次の更新で伝わり、進行中の更新を中断することはありません。

## 例

```tsx
import { state } from 'synstate-next';

// The primitive `createState` wraps: one object with `set` and `update`.
const count = state(0);

const mut_seen: number[] = [];

count.subscribe((n) => {
    mut_seen.push(n);
});

count.set(1);

count.update((n) => n + 1);

// An equal value passes nothing on.
count.set(2);

assert.deepStrictEqual(mut_seen, [0, 1, 2]);
```
