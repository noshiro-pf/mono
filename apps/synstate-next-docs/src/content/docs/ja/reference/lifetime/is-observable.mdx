`value` が、このパッケージのこのコピーの Observable かどうかを返します。

## 例

```tsx
import { createState, isObservable } from 'synstate-next';

const [count] = createState(0);

assert.isTrue(isObservable(count));

assert.isFalse(isObservable({ value: 0 }));
```
