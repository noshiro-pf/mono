`undefined` のイベントソースと、それを流す関数です。

## 例

```tsx
import { createEventEmitter, scan } from 'synstate-next';

const [clicked, click] = createEventEmitter();

const clicks = clicked.pipe(scan((n) => n + 1, 0));

click();

click();

assert.strictEqual(clicks.value, 2);
```
