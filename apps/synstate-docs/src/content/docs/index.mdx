## Features

<CardGrid>
    <Card title="Simple State Management" icon="pencil">
        Easy-to-use `createState` and `createReducer` similar to React
        `useState` / `useReducer` for global state.
    </Card>
    <Card title="Built-in Async Operators" icon="setting">
        `debounce`, `throttle`, `switchMap`, and more — handle complex async
        flows in a unified, declarative API without external libraries.
    </Card>
    <Card title="Predictable Performance" icon="rocket">

Glitch-free O(n) propagation, within **{/* bench:summary/synstate-worst-over-fastest */}5.1{/* /bench */}×** of the fastest library in each of the six benchmark scenarios. Among the other libraries measured in all six, worst cases range from {/* bench:summary/others-least-worst-over-fastest */}2.1{/* /bench */}× ({/* bench:summary/others-least-worst-library */}Preact Signals{/* /bench */}) to {/* bench:summary/others-most-worst-over-fastest */}> 15,625{/* /bench */}× ({/* bench:summary/others-most-worst-library */}RxJS{/* /bench */}). Speed is not where SynState stands out; [Why SynState?](/mono/synstate/guides/why-synstate/#glitch-free-at-linear-cost) says what does. See [the benchmark summary](/mono/synstate/guides/library-comparison/benchmark/#how-to-read-this-page).

    </Card>
    <Card title="Lightweight" icon="seti:favicon">
        {/* bundle-size:synstate */}~6.6 kB min+gzip{/* /bundle-size:synstate */} with two external runtime dependencies,
        one of which depends on the other.
    </Card>
    <Card title="React-Optimized" icon="seti:react">
        Fully compatible with React Compiler. `synstate-react-hooks` lets you
        add global state to any component in just a few lines.
    </Card>
    <Card title="Framework Agnostic" icon="random">
        Core library works as-is with vanilla JavaScript, Vue, Svelte, or any
        framework. For React and Preact, hooks wrappers are available. For
        Preact, a Preact Signals integration is also provided.
    </Card>

</CardGrid>
