{/* jsdoc-description */}
ソースの値を無視して、すべての発行値を定数値にマッピングします。
値は変わりませんが、ソースが発行するたびに発行します。`map(() => value)` は 2 回目以降の結果を等しいとして止めるので、イベントを値に変えるときはこちらを使ってください。値の型は `as const` を付けたときと同じく書いたとおりに推論され、`mapTo('reset')` は `string` ではなく `'reset'` になります。
{/* /jsdoc-description */}

## 使用例

```tsx
//  Timeline:
//
//  click$    MouseEvent   MouseEvent   MouseEvent
//  count$    1            1            1
//
//  Explanation:
//  - mapTo maps all emitted values to a constant value
//  - Ignores the source values entirely
//  - Useful for converting events to signals

const click$ = source<string>();

const one$ = click$.pipe(mapTo(1));

const valueHistory: number[] = [];

one$.subscribe((value) => {
    valueHistory.push(value);
});

click$.next('click1');

click$.next('click2');

click$.next('click3');

assert.deepStrictEqual(valueHistory, [1, 1, 1]);
```
