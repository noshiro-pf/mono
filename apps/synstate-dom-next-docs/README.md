# synstate-dom-next-docs

The documentation site for [synstate-dom-next](../../libs/synstate-dom-next),
the from-scratch rebuild of synstate-dom on
[synstate-next](../../libs/synstate-next), built with
[Astro Starlight](https://starlight.astro.build/), in English and Japanese.
Published at <https://noshiro-pf.github.io/mono/synstate-dom-next/> by
`.github/workflows/deploy-pages.yml`.

## Development

```sh
pnpm run dev      # start the dev server
pnpm run build    # build the site into dist/
pnpm run gen      # re-embed the samples, the benchmark results and the bundle sizes
```

Pages live in `src/content/docs/` (Japanese under `src/content/docs/ja/`).
Nothing on them is typed in that is kept anywhere else:

- **Code blocks** are files under `samples/`, embedded by `gen:samples`
  (`scripts/embed-samples.mts` maps each page to its files, in order).
  `check:types` checks them against synstate-dom-next's built types, so
  `pnpm run ws:build` first.
- **Benchmark figures** are generated by `gen:benchmark` from
  `apps/synstate-dom-benchmark/RESULTS-NEXT.md`, which
  `pnpm run benchmark:repeat -- --next` writes there, between
  `<!-- benchmark:<key> -->` markers.
- **Bundle sizes** are generated by `gen:bundle-size` from
  `apps/synstate-dom-benchmark/BUNDLE-SIZE-NEXT.md`, which
  `pnpm run bundle-size -- --next` writes there, between
  `<!-- bundle-size:<key> -->` markers, in the prose as in the tables.
