## Features

<CardGrid>
    <Card title="Made for SynState" icon="star">

The graph you build with synstate-next's operators ends in the DOM: each binding is a leaf of that graph, with nothing converted on the way. On the operations of js-framework-benchmark it takes {/* benchmark:next-over-dom-min */}0.78{/* /benchmark */}× to {/* benchmark:next-over-dom-max */}1.00{/* /benchmark */}× synstate-dom's time.

    </Card>
    <Card title="Bindings run on a settled graph" icon="approve-check">
        An update propagates through the whole graph first, and only then are
        the bindings it reached run, each once. A binding never sees a
        half-updated graph, and `If` and `For` mount and unmount outside any
        propagation.
    </Card>
    <Card title="Fine-grained, called once" icon="rocket">
        Your component function is called once, when it mounts. After that, an
        update writes straight to the DOM leaves bound to what changed: an
        attribute, a property or a text node. Nothing is diffed.
    </Card>
    <Card title="No compiler" icon="setting">
        All you need is TypeScript's standard `"jsx": "react-jsx"` and
        `jsxImportSource`. There is no Babel or Vite plugin to configure.
    </Card>
    <Card title="Reactivity in the types" icon="pencil">
        Wherever JSX takes data, you pass an observable or a `constant(...)`,
        never a plain value. If you read a snapshot by mistake, you get a type
        error instead of a view that silently stops updating.
    </Card>
    <Card title="No leaks by construction" icon="random">
        Everything made while a component mounts belongs to the owner it mounts
        in. Close a branch or remove a row, and every derivation, binding and
        subscription made inside it goes with it.
    </Card>

</CardGrid>
