## Features

<CardGrid>
    <Card title="Made for synstate-next" icon="star">

The graph you build with synstate-next's operators ends in the DOM: each binding is an end of that graph, with nothing converted on the way. A component can hand a binding any observable of the graph, async steps included.

    </Card>
    <Card title="Bindings run once every value is up to date" icon="approve-check">
        An update propagates through the whole graph first, and only then are
        the bindings it reached run, each once. A binding never sees a
        half-updated graph, and `If` and `For` mount and unmount outside any
        propagation.
    </Card>
    <Card title="Fine-grained, called once" icon="rocket">

Your component function is called once, when it mounts. After that, an update writes straight to the DOM bound to what changed: an attribute, a property or a text node. Nothing is diffed, and on the operations of js-framework-benchmark it takes at most {/* benchmark:next-over-solid-max */}1.31{/* /benchmark */}× Solid's time.

    </Card>
    <Card title="No compiler" icon="setting">
        All you need is TypeScript's standard `"jsx": "react-jsx"` and
        `jsxImportSource`. There is no Babel or Vite plugin to configure.
    </Card>
    <Card title="Reactivity in the types" icon="pencil">
        Wherever JSX takes data, you pass an observable or a `constant(...)`,
        never a plain value. If you read a snapshot by mistake, you get a type
        error instead of a view that silently stops updating.
    </Card>
    <Card title="No leaks by construction" icon="random">
        Close a branch or remove a row, and every derivation, binding and
        subscription made while it was being mounted is cleaned up with it,
        along with the timers and requests of its operators. There is nothing
        to unsubscribe by hand.
    </Card>

</CardGrid>
