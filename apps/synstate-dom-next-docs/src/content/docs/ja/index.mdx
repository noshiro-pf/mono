## 特徴

<CardGrid>
    <Card title="synstate-next のための UI" icon="star">

synstate-next のオペレーターで組んだグラフは、そのまま DOM で終わります。束縛の 1 つ 1 つがグラフの末端で、途中で値を変換することはありません。コンポーネントは、非同期の段も含めて、グラフのどの Observable でも束縛に渡せます。

    </Card>
    <Card title="束縛はすべての値が新しくなった後に動く" icon="approve-check">
        更新はまずグラフ全体に伝わり、その後で、届いた束縛がそれぞれ 1
        回だけ実行されます。束縛が更新途中のグラフを見ることはなく、`If` と
        `For` のマウントとアンマウントも伝播の外で行われます。
    </Card>
    <Card title="細粒度、呼び出しは 1 回" icon="rocket">

コンポーネント関数はマウント時に 1 回呼ばれるだけです。その後の更新は、変わったものに束縛した DOM の末端（属性・プロパティ・テキストノード）に直接書き込みます。差分は取らず、js-framework-benchmark の操作では、時間は Solid の最大 {/* benchmark:next-over-solid-max */}1.31{/* /benchmark */} 倍です。

    </Card>
    <Card title="コンパイラ不要" icon="setting">
        必要なのは TypeScript 標準の `"jsx": "react-jsx"` と `jsxImportSource`
        だけです。Babel や Vite のプラグインを設定する必要はありません。
    </Card>
    <Card title="リアクティブかどうかが型でわかる" icon="pencil">
        JSX がデータを受け取る場所には、Observable か `constant(...)`
        を渡し、素の値は渡しません。うっかりスナップショットを読んで渡すと、黙って更新が止まる画面ではなく型エラーになります。
    </Card>
    <Card title="構造上リークしない" icon="random">
        分岐を閉じたり行を消したりすると、それをマウントするときに作った派生・束縛・購読も、そのオペレーターのタイマーやリクエストと一緒に片付きます。手で購読を解除するものはありません。
    </Card>

</CardGrid>
