## Features

<CardGrid>
    <Card title="Made for SynState" icon="star">

synstate-dom is the UI library that connects most directly to SynState's runtime: the graph ends in the DOM, with nothing converted on the way. In [SynState's benchmark summary](/mono/synstate/guides/library-comparison/benchmark/#how-to-read-this-page), SynState stays within {/* bench:summary/synstate-worst-over-fastest */}2.7{/* /bench */}× of the fastest library in every scenario: {/* bench:summary/synstate-alone-in-single-digits */}the only library measured in all of them whose worst case stays in single digits{/* /bench */}.

    </Card>
    <Card title="Simple, and rarely slow" icon="pencil">

One way to write each thing, rather than extra forms that only win a row of a benchmark. On the operations of js-framework-benchmark, its slowest operation takes {/* benchmark:worst/synstate-dom */}1.56{/* /benchmark */}× the fastest library's time: {/* benchmark:placement/behind */}behind Solid, Preact and Preact + Signals{/* /benchmark */}, and well ahead of React's {/* benchmark:worst/react */}3.79{/* /benchmark */}×.

    </Card>
    <Card title="Fine-grained, called once" icon="rocket">
        Your component function is called once, when it mounts. After that, an
        update travels through the synstate graph and writes straight to the one
        DOM leaf bound to it: an attribute, a property or a text node.
    </Card>
    <Card title="No compiler" icon="setting">
        All you need is TypeScript's standard `"jsx": "react-jsx"` and
        `jsxImportSource`. There is no Babel or Vite plugin to configure.
    </Card>
    <Card title="Reactivity in the types" icon="approve-check">
        Wherever JSX takes data, you pass an observable or a `constant(...)`,
        never a plain value. So if you read a snapshot by mistake, you get a
        type error instead of a view that silently stops updating. And a prop
        holds the bindable itself, not a value read from it, so you can
        destructure props or give them defaults without breaking anything.
    </Card>
    <Card title="No leaks by construction" icon="random">
        `If`, `Match` and `For` each mount what they show in a scope of their
        own. Close a branch or remove a row, and every derivation and
        subscription made inside it goes away with it.
    </Card>

</CardGrid>
