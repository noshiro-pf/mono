## Features

<CardGrid>
    <Card title="Fine-grained, called once" icon="rocket">
        A component function is called once, when it is mounted. An update
        travels through the synstate graph and writes to the one DOM leaf bound
        to it: an attribute, a property or a text node.
    </Card>
    <Card title="No compiler" icon="setting">
        TypeScript's standard `"jsx": "react-jsx"` and `jsxImportSource` are all
        it needs. There is no Babel or Vite plugin to configure.
    </Card>
    <Card title="Reactivity in the types" icon="approve-check">
        A slot that takes data accepts an observable, a `constant(...)` or a
        `view(...)`, never a plain value. Reading a snapshot by mistake is a
        type error, not a view that silently stops updating.
    </Card>
    <Card title="No leaks by construction" icon="random">
        `If`, `Match` and `For` mount what they show in a scope of their own.
        Closing a branch or removing a row disposes every derivation and
        subscription made inside it.
    </Card>
</CardGrid>
