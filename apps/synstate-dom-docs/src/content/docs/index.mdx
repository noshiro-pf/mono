## Features

<CardGrid>
    <Card title="Fine-grained, called once" icon="rocket">
        Your component function is called once, when it mounts. After that, an
        update travels through the synstate graph and writes straight to the one
        DOM leaf bound to it: an attribute, a property or a text node.
    </Card>
    <Card title="No compiler" icon="setting">
        All you need is TypeScript's standard `"jsx": "react-jsx"` and
        `jsxImportSource`. There is no Babel or Vite plugin to configure.
    </Card>
    <Card title="Reactivity in the types" icon="approve-check">
        Wherever JSX takes data, you pass an observable, a `constant(...)` or a
        `view(...)`, never a plain value. So if you read a snapshot by mistake,
        you get a type error instead of a view that silently stops updating.
    </Card>
    <Card title="No leaks by construction" icon="random">
        `If`, `Match` and `For` each mount what they show in a scope of their
        own. Close a branch or remove a row, and every derivation and
        subscription made inside it goes away with it.
    </Card>
</CardGrid>
