## 特長

<CardGrid>
    <Card title="SynState のために" icon="star">

synstate-dom は SynState のランタイムに最も直接つながる UI ライブラリです。グラフは途中で何も変換されずに DOM で終わります。[SynState のベンチマークの概要](/mono/synstate/ja/guides/library-comparison/benchmark/#このページの読み方)では、SynState はどのシナリオでも最速のライブラリの {/* bench:summary/synstate-worst-over-fastest */}2.7{/* /bench */} 倍以内に収まります。{/* bench:summary/synstate-alone-in-single-digits */}すべてのシナリオで計測したライブラリのうち、最悪のケースでも1桁倍に収まるのは SynState だけです{/* /bench */}。

    </Card>
    <Card title="シンプルで、遅くなりにくい" icon="pencil">

1 つのことに 1 つの書き方を保ち、ベンチマークの 1 行だけで勝つための書き方は増やしません。js-framework-benchmark の操作では、最も遅い操作でも最速のライブラリの {/* benchmark:worst/synstate-dom */}1.56{/* /benchmark */} 倍で、{/* benchmark:placement/behind */}Solid・Preact・Preact + Signals には及びません{/* /benchmark */}が、React の {/* benchmark:worst/react */}3.79{/* /benchmark */} 倍を大きく下回ります。

    </Card>
    <Card title="細粒度、呼ぶのは 1 回だけ" icon="rocket">
        コンポーネント関数が呼ばれるのはマウント時の 1 回だけです。更新は
        synstate のグラフを伝わって、束縛された DOM
        の葉（属性・プロパティ・テキストノード）に直接書き込まれます。
    </Card>
    <Card title="コンパイラ不要" icon="setting">
        TypeScript 標準の `"jsx": "react-jsx"` と `jsxImportSource`
        だけで動きます。Babel や Vite のプラグインを設定する必要はありません。
    </Card>
    <Card title="リアクティブかどうかが型でわかる" icon="approve-check">
        データを受け取るスロットに渡せるのは Observable か `constant(...)`
        だけで、素の値は渡せません。うっかりスナップショットを読んで渡しても、更新されないビューができあがるのではなく、型エラーになります。props
        も値を読み出したものではなく Bindable
        そのものなので、分割代入しても、デフォルト値を付けても壊れません。
    </Card>
    <Card title="そもそもリークしない作り" icon="random">
        `If`・`Match`・`For`
        は、表示するものをそれぞれのスコープでマウントします。分岐を閉じたり行を消したりすると、その中で作った派生と購読はすべて破棄されます。
    </Card>

</CardGrid>
