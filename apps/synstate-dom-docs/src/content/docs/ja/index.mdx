## 特長

<CardGrid>
    <Card title="細粒度、1 回だけ呼ぶ" icon="rocket">
        コンポーネント関数はマウント時に 1 回だけ呼ばれる。更新は synstate
        のグラフを伝わり、束縛された DOM
        の葉（属性・プロパティ・テキストノード）に直接書き込まれる。
    </Card>
    <Card title="コンパイラなし" icon="setting">
        TypeScript 標準の `"jsx": "react-jsx"` と `jsxImportSource`
        だけで動く。設定する Babel や Vite のプラグインはない。
    </Card>
    <Card title="リアクティビティを型で表す" icon="approve-check">
        データを受け取るスロットは Observable・`constant(...)`・`view(...)`
        だけを受け付け、素の値は受け付けない。スナップショットを誤って読むと、更新されないビューではなく型エラーになる。
    </Card>
    <Card title="構造上リークしない" icon="random">
        `If`・`Match`・`For`
        は表示するものをそれぞれのスコープでマウントする。分岐を閉じたり行を消したりすると、その中で作った派生と購読がすべて破棄される。
    </Card>
</CardGrid>
