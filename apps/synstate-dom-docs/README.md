# synstate-dom-docs

The documentation site for [synstate-dom](../../libs/synstate-dom), built with
[Astro Starlight](https://starlight.astro.build/), in English and Japanese.
Published at <https://noshiro-pf.github.io/mono/synstate-dom/> by
`.github/workflows/deploy-pages.yml`.

## Development

```sh
pnpm run dev      # start the dev server
pnpm run build    # build the site into dist/
pnpm run gen      # re-embed the samples and the benchmark results
```

Pages live in `src/content/docs/` (Japanese under `src/content/docs/ja/`).
Nothing on them is typed in that is kept anywhere else:

- **Code blocks** are files under `samples/`, or the README samples of
  synstate-dom, embedded by `gen:samples` (`scripts/embed-samples.mts` maps
  each page to its files). `check:types` checks them against synstate-dom's
  published types, so `pnpm run ws:build` first.
- **Benchmark figures** are generated by `gen:benchmark` from
  `apps/synstate-dom-benchmark/RESULTS.md`, between
  `<!-- benchmark:<key> -->` markers. After re-running the benchmark, run
  `pnpm run gen` here.
