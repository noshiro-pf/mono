# color-demo-app

The demo page for picking N colours that stay easy to tell apart. It shows the
generated palette against the contrast thresholds, using the `color/` half of
`ts-utils-additional`.

Written for the article
[見分けやすい N 色をうまく選ぶ関数を作ったよ](https://qiita.com/pikohideaki/items/59415524503f833ce41e).

Restored from `experimental/` — see
[docs/experimental-inventory.md](../../docs/experimental-inventory.md).

## Running it

```sh
pnpm run dev      # Vite dev server
pnpm run build    # production build into `build/`
pnpm run preview  # serve that build
```
